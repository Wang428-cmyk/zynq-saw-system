# 大模型辅助资料整理与验证记录

项目硬件方案、FPGA 逻辑、嵌入式程序及上位机软件来自团队工程。辅助工作包括文献整理、报告编排、源码打包、构建入口编写和实验记录核验。

## 文献内容核对

整理无线无源 SAW 技术综述及高速读出器论文，核对作者、题名、期刊、DOI 和研究方法，形成与 Zynq/AD9361 读出架构对应的参考资料。记录同时区分文献方法、项目实现与测量指标。

## 引用格式整理

核对八篇参考文献的作者、题名、卷期、页码或文章编号及 DOI，统一报告中的顺序编码和排版。

## 文件与执行入口核验

整理 Python 执行入口、完整性校验命令和文件 SHA-256。Windows 下使用 Python 执行验证，获得 `PYTHON_OK`、完整性校验通过及退出码 0。

## 技术资料汇总

对照赛道指南、文档模板和设计报告整理系统结构、器件型号、工具版本、实现资源与实验记录。当前技术报告位于 `report/design_report.docx` 和 `report/design_report.pdf`。

## 软件构建与会话审计

形成 Vitis 2021.2 平台、BSP、应用、FSBL 和 Bootgen 构建脚本，并以新工作区和跨目录构建核对输出。将历史采集记录核验流程整理为 `skill/sensor-session-audit/`，按会话、轮次、通道与有效标志输出可复核统计。上位机与 Skill 自动化测试记录位于 `sim/results/`。
